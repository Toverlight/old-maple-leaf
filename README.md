# (outdated version) MapleLeaf

My game engine (semi-finished) written in C++20, using OpenGL to handle the graphics.

This was my first formal attempt to practice opengl in my engine project.

*This repo is only a reupload as the archive.*

> ***Attention***: The project name *MapleLeaf* is used in this project originally, however, for some reasons, the project didn't continue. After about five months, my another game engine with a more modern architecture originated, and it retained this name. That work I've been developing the longest, and also my most successful, is exactly [MapleLeaf](https://github.com/Toverlight/MapleLeaf).
